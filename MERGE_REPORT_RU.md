# Перенос изменений в Tournament_Fix

Дата: 9 октября 2026 года.

Основа: `Kazdoyby_Tournament_Fix_v1_4.zip`. Источник новых изменений: загруженный пользователем `Kazdoyby_Public-main (2) (1).zip`.

## Результат сравнения

У двух архивов совпали 34 общих файла. Изменены только `public/index.html` и `public/app.css`; добавлен `public/kazdoyby-board.png`.

В новом архиве отсутствовали четыре исходные SQL-миграции `001–004` и пять файлов тестов из Tournament_Fix. Они сохранены в объединённой сборке. Отсутствие папки в новом архиве не трактовалось как запрос на удаление функций.

## Что перенесено

| Файл | Изменение |
| --- | --- |
| `public/index.html` | Вместо декоративной мини-доски используется изображение главной страницы |
| `public/app.css` | Размеры, тень, наклон и отображение изображения на узком экране |
| `public/kazdoyby-board.png` | Изображение из предоставленного архива |

Эти три файла перенесены целиком из предоставленного ZIP. Игровые скрипты внутри HTML остаются такими же, как в Tournament_Fix; различия HTML касаются только мини-доски и её оформления.

## Что сохранено из Tournament_Fix

Без изменения содержимого сохранены `server.js`, `tournament-server.js`, `tournament-play.js`, `turn-pool.js`, `turn-worker.js`, `game-engine.js`, `room-control.js`, `social-server.js`, `avatars-server.js`, все существующие внешние JavaScript-файлы в `public`, исходные SQL `001–004`, прежние тесты и файлы зависимостей.

Таким образом сохранены серверные турнирные ходы, ограниченный поиск ботов, синхронизация позиции, исправленный таймер, окно результата, три уровня сложности, удаление/скрытие турнирной истории, рассадка организатором, наблюдатели, аватары, друзья, чаты, приглашения, языки и темы. Это подтверждается побайтовым сравнением указанных файлов; функциональные проверки перечислены в `QA_RU.md`.

## Что добавлено для нового сервера

- `supabase/000_base_schema.sql` — создание основных игровых таблиц в новом проекте Supabase. Чужую существующую схему скрипт не перезаписывает.
- `supabase/verify_install.sql` — проверка наличия таблиц, функций, полей и прав доступа.
- `tests/fresh-install.test.cjs` — проверка установки на пустую базу и защиты существующих таблиц.
- `NEW_SERVER_GUIDE_RU.md` и `START_NEW_SERVER_RU.html` — полный гайд: база, ключи, GitHub, Render, регистрация, SMTP, диагностика и обновление. HTML можно открыть двойным щелчком и распечатать.
- `server.env.example` — шаблон переменных для локального запуска; правила исключения локальных секретов из Git.

`README_RU.md` и `QA_RU.md` дополнены инструкциями и результатами объединения. Список SHA-256 исходных файлов включён в `SOURCE_HASHES.json` для самостоятельной проверки сохранённого кода.

## Границы работы

Переносились изменения, фактически присутствующие в загруженном архиве. Других отличий серверного кода между этими двумя версиями не обнаружено. Облачные проекты не создавались и действующий сайт не обновлялся; архив подготовлен для установки по приложенному руководству.
