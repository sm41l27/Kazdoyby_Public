# Каздойбы: казахский, русский и английский

В верхней части сайта добавлен выбор языка: **Қазақша / Русский / English**.
В окне настройки игры есть такой же переключатель. Они работают синхронно.

Язык по умолчанию — казахский. Выбор запоминается в браузере и восстанавливается
после обновления страницы. Переключение языка не перезагружает игру и не меняет
позицию на доске, очередь хода, таймер или подключение к комнате.

Переведены главная страница, настройки игры, аккаунт, правила, подсказки,
сообщения комнат, подписи игроков, история ходов и игр, результаты по времени.
Имена людей, email, введённые значения и коды комнат сохраняются как введены.
Названия цветов и команд в сохранённых данных остаются в исходном формате:
перевод применяется при отображении. Это сохраняет совместимость с сервером
и предыдущими сохранениями.

## Запуск

1. Распакуйте архив и откройте терминал в папке `Kazdoyby_Public-main`.
2. Используйте Node.js 20 или новее, как указано в `package.json`.
3. Установите зависимости:

   ```sh
   npm ci
   ```

4. Запустите сервер:

   ```sh
   npm start
   ```

5. Откройте `http://localhost:3000` в браузере.

Если на сервере задана переменная `PORT`, используйте соответствующий порт.
Для установленной версии сайта перенесите всю папку `public` из этого архива:
кроме изменённых файлов в ней есть новые файлы переводов. Затем обновите страницу.

## Файлы

- `public/translations.js` — русский и английский словари. Исходный казахский
  текст служит ключом. Параметры в фигурных скобках нужно сохранять при правке.
- `public/i18n.js` — выбор языка, сохранение настройки и обновление интерфейса.
- `public/i18n.css` — оформление переключателей и адаптация длинных подписей.
- `public/index.html`, `public/auth.js`, `public/network.js` — подключение переводов.
- `server.js` и `package.json` — без изменений относительно присланного архива.
- `package-lock.json` — зафиксированные зависимости для `npm ci`.

## Проверка

В Chromium проверены переключение и сохранение языка, поля аккаунта,
офлайн-ходы и отмена, неизменность состояния игры и таймера, история взятий,
правила и результаты по времени. Проверен мобильный экран шириной 390 пикселей.

Онлайн-интерфейс проверен с тестовыми ответами аккаунта и Socket.IO:
ошибки комнат, список игроков, подписи ИИ, история матчей и командный результат.
Реальные вход, регистрация и запись результатов в Supabase не проверялись:
в архиве нет конфигурации вашего сервиса. Для этих функций сохраняются
существующие переменные сервера `SUPABASE_URL`, `SUPABASE_SECRET_KEY` и
`SUPABASE_PUBLISHABLE_KEY`.

Типовые ошибки авторизации переведены. Неизвестные сообщения внешнего сервиса
отображаются в исходном виде, чтобы сохранить диагностическую информацию.
